# AWS Agent Registry

- **Service code:** `agent-registry`
- **Consola:** https://console.aws.amazon.com/servicequotas/home/services/agent-registry/quotas

## Ver las cuotas actuales

```bash
aws service-quotas list-service-quotas --service-code agent-registry \
  --query 'Quotas[].[QuotaCode,QuotaName,Value,Adjustable]' --output table
```

## Pedir el aumento

```bash
aws service-quotas request-service-quota-increase \
  --service-code agent-registry \
  --quota-code <QUOTA_CODE> \
  --desired-value <VALOR> \
  --region <REGION>
```
