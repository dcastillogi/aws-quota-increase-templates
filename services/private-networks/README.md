# AWS Private 5G

- **Service code:** `private-networks`
- **Console:** https://console.aws.amazon.com/servicequotas/home/services/private-networks/quotas

## List current quotas

```bash
aws service-quotas list-service-quotas --service-code private-networks \
  --query 'Quotas[].[QuotaCode,QuotaName,Value,Adjustable]' --output table
```

## Request an increase

```bash
aws service-quotas request-service-quota-increase \
  --service-code private-networks \
  --quota-code <QUOTA_CODE> \
  --desired-value <VALUE> \
  --region <REGION>
```
