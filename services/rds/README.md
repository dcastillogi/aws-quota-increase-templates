# Amazon Relational Database Service (RDS)

- **Service code:** `rds`
- **Consola:** https://console.aws.amazon.com/servicequotas/home/services/rds/quotas

## Ver las cuotas actuales

```bash
aws service-quotas list-service-quotas --service-code rds \
  --query 'Quotas[].[QuotaCode,QuotaName,Value,Adjustable]' --output table
```

## Pedir el aumento

```bash
aws service-quotas request-service-quota-increase \
  --service-code rds \
  --quota-code <QUOTA_CODE> \
  --desired-value <VALOR> \
  --region <REGION>
```
